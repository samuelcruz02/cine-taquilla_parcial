# Sistema de taquilla de cine

Aplicación web que simula el control de taquilla de un cine: login, registro de funciones con cálculo de recaudación, clave de seguridad, cambio de asientos con recargo por horario, gráfica de líneas y foto de control.

## Cómo usarla

Abre `index.html` en el navegador o entra al enlace de GitHub Pages.

- Usuario: `Cinecali`
- Contraseña: `Estrenos`
- Clave para continuar registrando: `CINE`

## Estructura del proyecto

```
index.html        estructura de las dos vistas (login y panel)
css/estilos.css   diseño y colores
js/app.js         lógica: login, cálculos, clave, gráfica, foto
img/              logo, favicon y fondo de la sala
docs/             guía, bocetos e ingeniería de requerimientos
```

## Tecnologías

HTML5, CSS3 y JavaScript sin librerías.
